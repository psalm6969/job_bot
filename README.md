# Job Hunter

Job Hunter — приложение для Windows, которое ищет вакансии по аналитике данных, BI и SQL, а также удалённую подработку с данными и таблицами. Оно проверяет hh.ru, RSS Хабр Карьеры, Hirify и публичные Telegram-каналы. Подходящие объявления со ссылками отправляются в указанный Telegram-чат.

Приложение запускает поиск сразу после нажатия кнопки и повторяет его примерно раз в два часа, пока окно открыто. Фильтры в `bot_app.py` учитывают ключевые слова, опыт, географию и формат работы. Идентификаторы обработанных объявлений сохраняются между запусками.

## Запуск на Windows

Нужен Python с Tkinter. Выполните команды в PowerShell из папки проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install requests
.\.venv\Scripts\python.exe bot_app.py
```

1. Создайте Telegram-бота через `@BotFather` и получите токен.
2. Для личных уведомлений откройте чат с ботом в Telegram и нажмите **Start**. В окне Job Hunter введите токен и числовой ID чата.
3. Укажите `https://api.telegram.org` в поле адреса Telegram API. В текущих исходниках при сбое отправки предусмотрен запасной сторонний прокси. Перед использованием своего токена проверьте список адресов в `send_telegram()`.
4. Нажмите **Запустить поиск**. Результат каждого прохода и ошибки видны в журнале окна.

## Настройки и файлы

| Файл | Назначение |
| --- | --- |
| `bot_app.py` | Основное приложение на Tkinter и точка входа для сборки EXE. |
| `channels.txt` | Необязательный список публичных Telegram-каналов, по одному имени на строку. Пустой список включает встроенные каналы. |
| `bot_config.json` | Локальные настройки окна, включая токен и ID чата. Создаётся при запуске поиска. |
| `seen_vacancies.txt` | Локальный список обработанных объявлений. |

## Сборка EXE

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller JobHunter.spec
```

Готовый файл появится в `dist\JobHunter.exe`. Для сборки также есть `Собрать_EXE.bat`. Запускайте приложение из папки с правом записи, чтобы оно могло сохранять настройки и историю.

Парсеры используют HTML сайтов и RSS. При изменении разметки конкретный источник может перестать возвращать вакансии до обновления парсера.
